# Collia support website

Public privacy and support pages for Collia, a photo editing and collage product by Guoxin Xian.

## Contents

- `index.html` — site entry page
- `privacy.html` — privacy policy
- `support.html` — product support information

## Scope

This repository contains the static support website and product documentation. The native iOS app source is maintained separately. It is an owned-product project, rather than a client case study.

## Local preview

From this directory, with Python 3 installed:

```sh
python3 -m http.server 8000
```

Open `http://localhost:8000/`. No build step is required for these static pages.

## Maintenance

Check product behavior and the current App Store purchase screen before changing feature, pricing or trial statements. Repository text alone does not establish current store availability or pricing.
